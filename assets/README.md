# CTC — expérience visuelle

Ouvrir le HTML en conservant le dossier assets à côté. Le pneu est une géométrie Three.js locale : carcasse, gomme, jante, rayons et boulons. Glisser ou utiliser les flèches ; commandes face, profil, zoom et pause. La photo fournie sert de repli sans WebGL. Le chargeur utilise un rendu du même modèle.

Sophie conserve le parcours guidé existant. WhatsApp, paiement et email restent simulés comme dans la démo initiale.

Images créées avec l’outil intégré image_gen :

- workshop.png : atelier automobile moderne à Maurice, équipements graphite et jaune, SUV sur pont, technicien examinant une roue, lumière tropicale, photographie commerciale panoramique réaliste, sans texte ni logo. Illustration fictive et non photographie des locaux réels.
- bronze-wheel.png : gros plan photographique d’une jante bronze multibranches avec pneu réaliste sur une équilibreuse, atelier graphite et jaune, métal usiné et rainures détaillées, lumière cinématographique, format paysage, sans texte ni logo.

Les photos personnalisées déjà enregistrées dans le navigateur restent prioritaires. La mascotte est un SVG animé créé pour cette interface.
